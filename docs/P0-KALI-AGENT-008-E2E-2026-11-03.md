```bash

```

The TCP 1514 session must exist. Confirm the Agent has a static IPv4/TCP Manager in `/var/ossec/etc/ossec.conf`; the installer will reject mismatched Manager routing.

If the legacy `kill-process0` is still deployed, its known SHA-256 is `5e9bc0e03b94584838dd97a64aab8906b168243c7bda2cf700803060cf24b3da`. **Do not run that legacy executable.** An existing legacy executable remains present unless separately removed by an approved change; the default installer does not replace it.
